隐私政策

生效日期 2026-11-17

小页将导入资料的本地副本、提取文字、生成的学习页、题目、作答记录、阅读位置和设置保存在这台 Mac。API 密钥保存在系统钥匙串。应用目前没有自建账号服务、广告或行为分析 SDK，也不提供跨设备同步。

当你选择联网生成或相关模型处理时，应用会向你配置的模型服务发送为该任务选定的资料文字、必要的 PDF 页面图像、模型指令和参数，并使用你的 API 密钥进行认证。目录识别可能需要发送目录／候选正文页面或标题。逐页问答发送当前讲解、对应原文和问题。测试连接会发送小型测试请求。供应商也会接收到网络请求通常包含的元数据，例如 IP 地址。生成过程中使用的资料可能含个人信息，请仅发送你有权使用的内容。

开发者不运营统一的模型转发服务。第三方服务对请求的留存、训练使用、费用和删除办法取决于你选择的供应商与账户约定；小页不能代其承诺不保存或不训练。选择服务前请查看其隐私政策。

离线阅读和练习已保存内容无需再次调用模型。不使用联网生成可避免新任务的资料发送；停止任务可取消后续处理并丢弃本次结果，但不能撤回已到达供应商的请求。

你可以在书架移除教材及其相关学习记录、本地副本；原始导入文件不会因此删除。在设置中清空对应服务的密钥并保存，可删除该服务的本机钥匙串记录。删除本机资料不会自动删除供应商已留存的数据，后者应向供应商申请。卸载应用未必清除本机资料或钥匙串条目。

若主动寻求支持，开发者会接收到你自行提供的邮件与诊断材料，仅用于处理该支持请求；请不要发送 API 密钥或未经授权的教材。

支持邮件与必要附件通常保留到工单结束后 90 天。若依法需要延长留存，将按适用要求处理。
